A faster drop-in for csv-reader 1.0.0: `solve.js` answers every case exactly as csv-reader does — the same columns, rows and broken-row errors (stray_cr, quote_junk, unterminated_quote, short_row, long_row) — and reads the text with slice-based scanning, quote-to-quote indexOf jumps and a one-split fast path for clean records, instead of one character at a time. `main.ts` is the harness driver: it reads the cases from /input/cases.json and writes the answers to /output/answers.json.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
